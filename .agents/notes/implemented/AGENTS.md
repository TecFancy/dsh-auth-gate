# AGENTS.md - Implemented Agent Notes

These notes describe shipped decisions. Follow [../README.md](../README.md) for
placement, naming, and format. **Keep each note current with what actually
shipped**: when code moves a file, renames something, or changes a key/default,
update the note's facts in the same change. Rewrite stale facts in place; do
not append change history. A reversal of the decision itself requires a new
note, not an edit to this one. Archive complete triplets that no longer guide
future work (see `archived/AGENTS.md`).
